Detailed Description

API for extracting model metadata from a BigWorld assets.bin packed database.

assets.bin is a packed key-value store (PDB) that ships alongside the game client. It contains, among other things:

  • hardpoint (HP_) transform matrices used to position turrets and modules,
  • BlendBone correction matrices needed to align part geometries,
  • render-set / LOD listings that map draw-call IDs to material (.mfm) paths.

The preferred usage pattern is to open a PDB handle once with assets_bin_pdb_open and then call query helpers as needed, rather than using the one-shot helpers that reload the PDB on every call.
