Query render-set and LOD information for a .visual resource.

visual_suffix must be a suffix path such as "ShipDir/ShipDir.visual". The pdb handle must have been obtained from assets_bin_pdb_open.

Parameters
pdbOpen PDB handle.
visual_suffixSuffix path of the visual resource to look up.
Returns
Heap-allocated assets_bin_visual_info_t, or NULL if not found.
